# 👨🏻‍💻 Nicolas Mariano de Azevedo

**`Engenheiro de Software`**

Tenho 21 anos e sou da região do Alto Tietê, em São Paulo. Atualmente, estou no 6º semestre do bacharelado em Engenharia de Software na Universidade de Mogi das Cruzes (UMC). Atuo como Gerente de Projetos e Pesquisador Líder no PVIC, onde direciono a arquitetura de software de uma plataforma de gestão para ONGs de proteção animal. Tenho forte interesse em desenvolvimento full-stack, ciência de dados e criação de tecnologia com impacto social.
